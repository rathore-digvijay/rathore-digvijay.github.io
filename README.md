## Deploy on GitHub Pages

1. Copy the contents of this folder into the root of `rathore-digvijay/rathore-digvijay` (replacing the old site).
2. Commit and push to the branch GitHub Pages serves (Settings → Pages).
3. Live at https://rathore-digvijay.github.io/rathore-digvijay/

## Things to change

- **Profile photo** — the hero `<img>` points at the absolute URL of your existing `img/profile.jpg`. If you keep the `img/` folder in the repo, change it to `img/profile.jpg`.
- **Blog titles** — three placeholder titles in the Writing section, all marked "coming soon". Replace or delete the section.
- **Fonts** — Bricolage Grotesque, IBM Plex Sans and IBM Plex Mono load from Google Fonts.

Styles are inline on the elements, so each page is self-contained and editable without hunting through a stylesheet.
